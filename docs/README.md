# 文档索引

本目录放需要独立成篇、长期保留的文档，如学习笔记、设计说明、实验记录、操作指南。项目做什么见根目录 [README](../README.md)，术语见 [GLOSSARY](../GLOSSARY.md)；当前任务的步骤与验收写在 PLAN，不放这里。

## 索引

| 文档 | 用途 |
|---|---|
| （[文件名](文件名.md)） | （一句话说明） |

（新增一篇就在这里补一行；子目录写一行指向它的 README 即可。完成填写后删除本提示和占位行。）

## 写法

- 先平铺在 docs/ 下；同一主题积累到三篇左右再收进子目录，子目录放自己的 README 作索引。
- 有先后顺序的系列用两位编号开头：01-xxx.md、02-xxx.md。
- 一篇只讲一件事；内容过时就更新或删除，不保留互相矛盾的版本。
- 文中术语以 GLOSSARY 为准，新术语确认后补进去。
